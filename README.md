# Codecademy Sliding Panel
A sliding panel that moves up and down from Codecademy jQuery course. 

## Tech Stack
- HTML
- CSS
- JavaScript
- jQuery

## Instructions
1. Clone or download zip file. 
2. Open index.html file in your browser.
3. You will see a slide up/slide down button in at the top center of the page. When you click the button, the panel will slide down with a message. Click the button again to get the panel to get the panel to slide up.
